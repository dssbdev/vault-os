# vault-os

My Obsidian second brain, organised so that both I and AI can find anything in it.

This repo is the system behind it: how the folders are laid out, what every note says about itself at the top, and the map an AI assistant reads before anything else. It comes with a demo vault you can open in Obsidian and explore. Everything in the demo vault is made up.

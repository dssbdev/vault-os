# Home Backup Plan

Right now every photo I have ever taken exists in exactly one place. If the laptop is stolen, dropped, or simply stops turning on one morning, all of it is gone. This project fixes that and then stops — it is a project, not a hobby, and it has an end.

## Goal

Get the files that actually matter onto three copies across two kinds of storage with one copy kept somewhere else, as described in [[backup-rule-321]]. Done when I have deleted a file on purpose and successfully restored it from a backup I did not set up that same day.

## Scope

In: photos, scanned documents, the notes vault, and the recipe file from [[recipe-box-app]]. Out: the operating system, installed programs, and downloads. Those are replaceable in an afternoon; a decade of photos is not.

The restore test is the step everyone skips, and skipping it is how people discover after the disaster that their backup had been silently failing for eight months.

# Backup plan v0 - everything in the cloud folder

> **Archived 2026-07-21. Superseded by [[home-backup-plan]].** This plan was wrong. Kept because it was confidently wrong for two years, and that is worth remembering.

## The plan, at the time

All important files live in the synced cloud folder. The cloud keeps a copy, the laptop keeps a copy - two copies, therefore backed up. Nothing else needed.

## Why it was wrong

Sync copies mistakes. Delete a file or let one corrupt, and every device has the damage within seconds. It protects against a dead laptop and nothing else. The full reasoning is in [[backup-rule-321]], and the decision that replaced it is in [[2026-08-02-backup-target-decision]].

⚠️ Any search that returns this note as the answer to "how are my files backed up?" is returning a dead plan. That is exactly why status lives in frontmatter.

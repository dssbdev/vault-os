# Web basics for one small page

A short free course on HTML, CSS and a little JavaScript, taken for exactly one reason: to build [[recipe-box-app]] without learning a framework I'll never use again.

## What I needed from it

- One HTML file with a list and a search box
- Enough CSS to make it readable from across the kitchen
- Enough JavaScript to filter a list as I type

## What I skipped

Everything about servers, build tools, and frameworks. Recorded as a deliberate cut in [[scope-cutting]].

## The one surprise

Loading a data file from disk is harder than it sounds — browsers block it for security. The fix is researched in [[2026-06-offline-first-web-pages]].

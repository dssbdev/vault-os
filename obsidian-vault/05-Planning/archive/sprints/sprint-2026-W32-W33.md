## End-of-sprint review

Filled 2026-08-16.

### Done

The recipe project has a decided format and three recipes in it, which was the genuinely uncertain part - everything left is typing and building. The backup destination is chosen and written up in [[2026-08-02-backup-target-decision]]. The kitchen ran two clean weeks. [[spaced-repetition]] became a proper note, and the weekly review habit survived both weeks, which it hasn't before.

### Missed

Both projects' *physical* steps: no working list view, no drive ordered, no backup copy in existence. The photo backlog moved zero metres in fourteen days.

### Patterns

**Two projects, neither finished.** Attention split evenly across both produced good thinking on both and shipped output on neither. Next sprint ranks them explicitly instead of pretending both are priority one.

**The uncertain work gets done, the tedious work doesn't.** Deciding a file format is interesting, so it happened. Typing in recipes and ordering a drive are dull and reversible-feeling, so they didn't. This is backwards - the dull steps are the ones that make a project real.

**Every miss this sprint was a first physical step.** Ordering, building, copying. Everything that stayed in my head got done.

### Rollover

List view, search box, drive order, first copy, photo backlog - all into [[sprint]], with the recipe project named as the single priority and the backup project cut back to two steps.

# Leaving the notes app for plain markdown files

## Context

Third notes app in four years, and the export from the second one had already lost all the formatting once. The new app's pricing page had just changed.

## Options considered

**Stay and pay.** Fine until the next change of terms, which is the problem.

**Another app.** The same decision again in two years.

**Plain markdown files in a folder, any editor on top.** No account, no lock-in, readable forever.

## Decision

Plain files. The deciding factor was the export: if leaving an app costs a weekend of repair work, the app owns the notes. The reasoning is written up in [[plain-text-files]]; the migration itself was [[notes-app-migration]].

## Revisit

Only if a plain-file editor stops existing, which is the point.
